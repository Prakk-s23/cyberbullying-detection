# Reported Results

According to the project report, the developed system was trained on **59,537 text samples** in English, Hindi, and Hinglish.

## Reported Performance

| Metric | Result |
|---|---:|
| Overall Accuracy | 88.96% |
| Combined F1-score | 87.72% |
| Hinglish Emotion F1-score | 99.01% |
| Sarcasm Detection | 95.89% |
| Cyberbullying Detection F1-score | 69.83% |

The trained model checkpoint and generated evaluation files are not included in this public repository.
