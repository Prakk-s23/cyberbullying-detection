# Dataset Information

The research project uses two datasets:

1. `combined_hate_speech_dataset.csv`
2. `mlt_hinghlish_dataset.csv`

The raw CSV files are intentionally not included in this public repository. Before redistributing a dataset, verify its original source, license, and redistribution terms.

The notebook expects the CSV files to be placed in this `data/` directory with the filenames above.

The project combines multilingual English, Hindi, and Hinglish text for multitask learning involving:

- Cyberbullying detection
- Emotion classification
- Sentiment analysis
- Sarcasm detection

For the exact dataset sources and citations, refer to the project report/manuscript.
